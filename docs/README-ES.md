# Xsilent Vault: Oculta Fotos

Bóveda para Android centrada en la privacidad para fotos, vídeos, PDF y archivos privados.

Xsilent Vault: Oculta Fotos está diseñada para ofrecer control local, sin necesidad de una cuenta, sin anuncios y sin almacenamiento obligatorio en la nube para el uso normal de la bóveda.

Website: https://tsidevstudio.com/apps/xsilent

Google Play: https://play.google.com/store/apps/details?id=com.xsilent.app

## Qué protege Xsilent

- Fotos
- Vídeos
- PDF
- Archivos privados

## Funciones centradas en la privacidad

- Bóveda protegida con PIN
- Acceso biométrico compatible
- PIN señuelo
- Copia de seguridad cifrada
- Papelera cifrada
- Visualización privada de PDF
- Herramientas de privacidad Clean Share
- Quick Lock y bloqueo automático
- Protección contra capturas y grabaciones de pantalla cuando sea compatible
- Funcionamiento local-first

## Modelo de privacidad

Xsilent está diseñada para reducir dependencias externas innecesarias durante el uso normal de la bóveda privada.

- No requiere una cuenta de Xsilent
- Sin anuncios
- Sin almacenamiento obligatorio en la nube
- Funcionamiento local-first
- Copias de seguridad cifradas bajo el control del usuario

## Acerca de este repositorio

Xsilent no se publica actualmente como una aplicación de código abierto.

Este repositorio proporciona información pública sobre el producto, documentación, enlaces de verificación y recursos relacionados con las versiones.

Por motivos de seguridad y propiedad intelectual, este repositorio no publica el código fuente de la aplicación, la arquitectura interna, detalles de la implementación criptográfica, mecanismos internos de autenticación, formatos internos de copias de seguridad ni otra información de implementación sensible para la seguridad.
