# Getting Started with Xsilent

Xsilent is a privacy-focused Android vault for photos, videos, PDFs and private files.

This guide covers public, user-facing concepts only.

## Install Xsilent

Use the official Google Play listing:

https://play.google.com/store/apps/details?id=com.xsilent.app

## Initial setup

After installation:

1. Open Xsilent.
2. Follow the on-screen setup flow.
3. Configure your main access PIN.
4. Enable supported biometric access if you want faster entry.
5. Review the available privacy and locking options.
6. Add private content to the vault using the app's supported import flows.

## Private content

Xsilent is designed to protect supported private content such as:

- Photos.
- Videos.
- PDFs.
- Private files.

## Privacy controls

Depending on device support and app version, Xsilent may provide:

- PIN access.
- Biometric access.
- Decoy PIN.
- Quick Lock.
- Automatic locking.
- Screenshot and screen-recording protection.
- Encrypted Trash.
- Encrypted backup.
- Clean Share privacy tools.

## Backups

If you use encrypted backup, treat the resulting backup as sensitive.

Keep copies only in locations you trust and verify that you can access your recovery material when needed.
