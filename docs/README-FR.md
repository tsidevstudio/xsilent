# Xsilent Vault : Masquer des photos

**Coffre-fort Android axé sur la confidentialité pour les photos, vidéos, PDF et fichiers privés.**

Xsilent Vault : Masquer des photos est conçu pour privilégier le contrôle local des données, sans compte obligatoire, sans publicité et sans stockage cloud requis pour une utilisation normale du coffre-fort.

## Version gratuite et Lifetime

Xsilent peut être installé gratuitement, sans compte, sans publicité et sans abonnement.

### Version gratuite

- 30 importations gratuites dans le coffre-fort principal
- 30 importations gratuites indépendantes dans le coffre-fort leurre
- Jusqu’à 10 fichiers par opération d’importation
- Faux code PIN et coffre-fort leurre inclus
- Sauvegarde chiffrée et restauration
- Corbeille chiffrée
- Consultation privée des PDF
- Protection par code PIN, Quick Lock et verrouillage automatique
- Security Center
- Aucune limite de temps

Une fois les importations gratuites utilisées, les fichiers déjà enregistrés restent accessibles.

Vous pouvez continuer à consulter, partager, exporter, supprimer, sauvegarder et restaurer vos fichiers.

La suppression d’un fichier ne rétablit pas une importation gratuite déjà utilisée.

### Lifetime — achat unique

- Nombre total d’importations illimité
- Jusqu’à 20 fichiers par opération d’importation
- Déverrouillage par empreinte digitale dissimulé
- Clean Share : flouter les visages et supprimer les métadonnées avant le partage
- Toutes les fonctionnalités de la version gratuite
- Aucun abonnement ni paiement récurrent

Google Play affiche le prix exact dans votre devise locale avant l’achat.

## Vos fichiers, votre choix

Xsilent utilise le sélecteur de photos d’Android pour choisir les photos et vidéos. Pour les PDF et autres documents compatibles, l’application utilise le sélecteur de documents du système Android.

**Xsilent n’a pas besoin d’accéder à l’ensemble de votre galerie de photos.** L’application traite uniquement les fichiers que vous sélectionnez ou partagez explicitement.

Les fichiers importés sont enregistrés sous forme de copies chiffrées dans le coffre-fort.

**Les fichiers originaux restent dans votre galerie ou à leur emplacement d’origine.**

Si vous souhaitez également les masquer à cet emplacement, supprimez-les manuellement après avoir vérifié que les copies chiffrées ont bien été importées.

Xsilent ne supprime pas automatiquement les fichiers originaux lors de l’importation.

## Modèle de confidentialité

Xsilent est conçu pour réduire les dépendances externes inutiles lors de l’utilisation normale du coffre-fort privé.

- Aucun compte Xsilent requis
- Aucune publicité
- Aucun stockage cloud requis
- Aucune autorisation d’accès étendu à la galerie de photos
- Fonctionnement local
- Sauvegarde chiffrée contrôlée par l’utilisateur
