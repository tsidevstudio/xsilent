# Xsilent

Privacy-first Android photo, video, PDF and file vault.

Xsilent is designed for local/offline use, with no required account, no ads and no required cloud storage.

## What Xsilent protects

- Photos
- Videos
- PDFs
- Private files

## Privacy-focused features

- PIN-protected vault
- Optional biometric access
- Decoy PIN
- Encrypted backup
- Encrypted Trash
- Private PDF viewing
- Clean Share privacy tools
- Auto-lock and quick-lock controls
- Screenshot and screen-recording protection where supported

## Privacy model

Xsilent is designed around local control.

- No required account
- No ads
- No required cloud storage
- Local/offline-first operation
